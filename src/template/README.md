# Template

Starter mod in `src/`. Shows a toast when the mod loads.

## Use

1. Enable the mod.
2. Load a save (or continue).
3. Look for the toast: **Template loaded**.

Check the console for `[author.template]`.

## Edit this mod

Set `id`, `name`, `author`, and `description` in `modinfo.ts`. Edit `main.ts`.

Copy `src/template/` to `src/<your-mod>/` when you want a second mod.
