# Sandustry Mod Template

This site documents the shared mod template kit: folder layout, builds, the framework (React, SDK, debug), UI components, and bundle patches.

To clone the repo and start a mod, see the [GitHub README](https://github.com/IrishBruse/SandustryModTemplate#readme).

Sandkit API types come from the [sandustry-modding-types](https://github.com/flamableassassin/sandustry-modding-types) submodule.
