# Hello World Example

Minimal sample mod. Shows a toast when the mod loads.

## Use

1. Enable the mod.
2. Load a save (or continue).
3. Look for the toast: **Hello World Example loaded**.

On hot reload the toast does not show again. Check the console for `[author.hello-world-example]`.

## Copy this mod

Copy `src/hello-world-example/` to `src/<your-mod>/`. Set `id`, `name`, `author`, and `description` in `mod.ts`.
