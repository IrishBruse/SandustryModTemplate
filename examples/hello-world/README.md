# Hello World Example

Minimal sample mod. Shows a toast when the mod loads.

## Use

1. Enable the mod.
2. Load a save (or continue).
3. Look for the toast: **Hello World loaded**.

On hot reload the toast does not show again. Check the console for `[example.hello-world]`.

## Copy this mod

Copy `examples/hello-world/` to `src/<your-mod>/`. Set `id`, `name`, `author`, and `description` in `mod.ts`.
