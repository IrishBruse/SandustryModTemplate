# I18n Example

Register translation strings with `i18n.register` and read them with `i18n.t`.

Pattern from workshop mods `thatsmaik.player-skins` and `electric131.battery-sensor`.

## Use

1. Enable the mod and load a save.
2. Look for the toast **Hello from i18n**.

## Copy this mod

Copy `examples/api/i18n/` to `src/<your-mod>/`. Add locales and keys in `main.ts`.
