# Custom Terrain Example

Register one terrain type with `terrains.register`.

Pattern from workshop mod `sandustry-labs.better-strataform`.

## Use

1. Enable the mod and load a save.
2. **Debug menu:** equip the Debug tool → **Terrain** brush → **Example Chalk**.
3. Paint chalk terrain on the map.

## Copy this mod

Copy `examples/content/custom-terrain/` to `src/<your-mod>/`. Change terrain id, hit points, and `colorHSL` in `main.ts`.

For powder elements instead of terrain, see [`custom-element`](../custom-element/).
