# UI Prompt Example

Show a text input dialog with `ui.prompt`.

Pattern from workshop mod `kpadula.waypoints`.

## Use

1. Enable the mod and load a save.
2. Press **U** (rebindable under Options → Controls).
3. Type a label in the dialog and confirm.
4. Look for a toast with your text.

## Copy this mod

Copy `examples/api/ui-prompt/` to `src/<your-mod>/`. Change binding id, default keys, and prompt copy in `main.ts`.

For key bindings without a dialog, see [`input-binding`](../../ui/input-binding/).
