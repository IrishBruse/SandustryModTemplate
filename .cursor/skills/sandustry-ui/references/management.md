# Management overlay

Full-screen `z-[10004]`.
HUD column stays visible.

| Tab      | Key | Detail        |
| -------- | --- | ------------- |
| Toolbox  | Tab | `toolbox.md`  |
| Building | Q   | `building.md` |
| Research | T   | `research.md` |
| Upgrades | U   | `upgrades.md` |

Detail pane: **Hover over an item to see details.** Toolbox/Building: drag to hotbar; **Disable Drag & Drop** if clicks stick.

Open with `window` `keydown` when a HUD button has focus.
