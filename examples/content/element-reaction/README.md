# Element Reaction Example

Register one contact reaction with `reactions.registerContact`.

Pattern from workshop mod `sandustry-labs.red-sand-production`.

## Use

1. Enable the mod and load a save.
2. Touch **Sand** to **Water** in the sandbox.
3. Sand converts to Wet Sand where they meet.

## Copy this mod

Copy `examples/content/element-reaction/` to `src/<your-mod>/`. Change inputs, outputs, and orientation in `main.ts`.

For element registration, see [`custom-element`](../custom-element/).
