# Example mods

Copy a folder here to `src/<your-mod>/` when you start a real mod. Each folder is a separate game mod.

| Folder | What it shows |
| --- | --- |
| [`hello-world`](hello-world/) | Toast on load — smallest copy target |
| [`overlay-hotkey`](overlay-hotkey/) | React overlay + Tailwind (**Alt+E**) |
| [`retro-game`](retro-game/) | Retro Console demo |
| [`management-button`](management-button/) | Management-column row |
| [`worker-api`](worker-api/) | Worker-thread `sandkit.api` |
| [`settings`](settings/) | All `configSchema` field types |
| [`custom-element`](custom-element/) | Register an element and paint at the mouse cell |
| [`input-binding`](input-binding/) | `api.input.registerBinding` + bound-key UI |
| [`events`](events/) | `api.events.on` subscribe and dispose |
| [`mod-assets`](mod-assets/) | Static `mod/` files + `assets.getUrl` |
| [`content-machine`](content-machine/) | Elements + structure + processor loop |

Shipped mods that are not samples live under [`../src/`](../src/): `selection-capture`, `debug` (debug builds only).
